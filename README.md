# Mapa de poder adquisitivo por barrio, Talca

Compara barrios de La Florida con el nororiente (Paseo Hacienda y Bicentenario Valles) usando un indice socioeconomico proxy por manzana.

- Fuente: Censo 2024 INE, base manzana-entidad y cartografia (region del Maule).
- Indice: promedio estandarizado de escolaridad, educacion terciaria, ocupados profesionales, computador, internet fija, uso de auto e hacinamiento (resta). Se expresa como percentil dentro de Talca urbana.
- No es ingreso en pesos: el Censo no pregunta ingresos.
- Referencia comunal: pobreza por ingresos de Talca 5,7% (Casen 2022).
